# 先方サーバー アップデート手順（2026-08-31 反映用）

先方 Windows Server は **インターネット不可**・**Git 不使用**です。  
新しいオフラインキット ZIP を Box で渡し、サーバーでは次のコマンドだけ実行します。

> 初回構築済みであること（`C:\apps\mhi-app` と Windows サービス `MhiProgressApi` があること）。  
> 初回構築は [オフライン構築手順.md](./オフライン構築手順.md) を参照。

---

## 先方サーバーでやること（これだけ）

管理者 PowerShell:

```powershell
Set-ExecutionPolicy RemoteSigned -Scope CurrentUser
mkdir C:\apps\kit -Force
tar -xf <受け取ったZIPのパス> -C C:\apps\kit
cd C:\apps\kit\mhi-app-offline-YYYYMMDD
.\deploy-offline.ps1
Get-Content C:\apps\mhi-app\RELEASE.txt
```

- `Expand-Archive` は使わない（`tar -xf` のみ）
- `.env`（CSV パス・JWT 等）はスクリプトが退避・復元する。手で消さない
- 所要約数分。完了後にブラウザで `http://<サーバー>/` を開く

### 反映後に画面で確認すること

1. **データ取込**（管理者）
   - 「自動取込」をオン
   - 時刻が **08:00** と **13:00** になっていること（必要なら追加・削除して保存）
   - 指定フォルダの 4 CSV が OK なら、その時刻に自動で取り込む（タスクスケジューラの追加設定は不要）
2. **部品一覧**
   - 行をクリックすると詳細が **ポップアップ** で開く
   - 閉じると、絞り込み・表示件数・ページ位置が残っていること
3. **マスタ管理**
   - 「外注先」タブは出ない（機能自体は残してある。タイムラインの外注先名は従来どおり）

## 開発側：ZIP を作って渡すまで

1. ビルド用 Windows（インターネットあり）でキット作成

```powershell
cd C:\apps\mhi-app\app\deploy
.\fix-ps1-encoding.ps1
.\make-offline-kit.ps1
```

成功の印:

```text
==> Created: C:\apps\mhi-app\dist-release\mhi-app-offline-YYYYMMDD.zip
```

2. 検証用（外向きなし）で **同じ ZIP** を `deploy-offline.ps1` し、上記の画面確認を通す
3. 検証に使った **同じ ZIP** を Box へアップロードし、先方 IT に渡す  
   （ファイル名・サイズ・SHA256 を添える）

詳細は [オフライン構築手順.md](./オフライン構築手順.md) の「アップデート」節。
