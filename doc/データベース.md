# データベース構成

`app/backend/prisma/schema.prisma` で定義。PostgreSQL 18。

## テーブル群

| 群 | テーブル | 役割 |
|----|---------|------|
| **① 取込** | `t_part`, `t_routing`, `t_shop_master`, `t_shop_name` | CSV からの生データ。ETL 洗い替え |
| **② 算出** | `t_part_status`, `t_timeline` | 算出結果。再計算で更新 |
| **③ アプリ固有** | `t_assignment`, `t_trouble`, `t_shelved`, `t_note` | 担当者・困りごと・保留・メモ。ETL でも保持 |
| **マスタ** | `m_param`, `m_milestone`, `m_shop_lt`, `m_calendar`, `m_vendor`, `m_category`, `m_kishu` | 算出・UI の挙動を規定 |
| **認証** | `m_user`, `t_user_role`, `m_user_kishu` | ログインユーザー・ロール・担当機種 |
| **監査** | `t_audit_log` | 操作履歴 |

> `m_owner` / `m_owner_kishu` は旧構成の非推奨テーブル（残存のみ）。新規は `m_user` 系を使用。

## データフロー

```
CSV → ①取込 → ②算出 → API → フロント
              ↑
           マスタ（再計算で反映）
③アプリ固有 ← ユーザー操作（ETL 非破壊）
```

## 関連ファイル

- スキーマ定義: `app/backend/prisma/schema.prisma`
- マイグレーション: `app/backend/prisma/migrations/`
- 取込ジョブ状態（ファイル）: `backend/data/ingest-job.json`（`INGEST_JOB_FILE` で変更可）
- 自動取込スケジュール（ファイル）: `backend/data/ingest-schedule.json`（`INGEST_SCHEDULE_FILE` で変更可。画面「データ取込」で編集）
