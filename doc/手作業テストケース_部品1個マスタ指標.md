# 手作業テストケース（部品1個 × マスタ → 指標）

取込済みデータから **部品を1件だけ固定**し、マスタを1項目ずつ変えて、一覧・詳細の指標が期待どおり変わるかを見る。

- **ローカル**で手順を試す → 起点は **基準日 2026-08-14・残 27**
- **検証環境** → 基準日 **2026-08-18・残 24**（同じ部品でも残日数が少なく見える）
- リリース当日 **8/20** は別表（参考）。当日はさらに残 22・赤 −2

- URL（ローカル）: `http://localhost:5173/`
- 管理者でログイン → 左メニュー **マスタ管理**
- 保存後は「再計算中…」が消えてから確認する
- **各ケースのあと、必ず元の値に戻す**
- **検証環境（20260818 キット初回構築直後）** … `npm run seed` → `npm run recompute` 済みであること（中間マイルストンに ◎ が付いていること）。未実施だと TC-06〜10 の `▼検査` タグが出ない

部品詳細の「残Shop数 × 4日/Shop」は表示が 4 固定なので、LT を変えたあとは **信用しない**。見るのは一覧の色・バッファ・残日数・滞留と、タイムラインの検査タグ。

## 1. 基準日が進んだとき

所要 24 日は固定。基準日だけ進むと残日数・バッファ・滞留が動く。検査の MM/DD は変わらない。

## 2. マスタを変えたとき（画面操作）

見る部品は常に **X000702855**。**ローカル（8/14・残 27・緑 +3）** を起点に 1 ケースずつ。終わったら戻す。

検証環境で同じ操作をする場合、残日数は **3 日少ない**（例: ローカル 27 のまま → 検証 24 のまま）。バッファの増減量は同じ。
