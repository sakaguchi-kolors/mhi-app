## 1. 実装済み（develop）

### 1.1 工程ヒートマップ

| 項目 | 内容 |
|---|---|
| 画面 | `/heatmap`（サイドバー「工程ヒートマップ」） |
| 詳細仕様 | [フェーズ2_工程ヒートマップ.md](フェーズ2_工程ヒートマップ.md) |
| 概要 | SHOP×期間で部品流入/在席を可視化。平常時比で黄/赤/濃赤を判定 |
| 主な API | `GET /api/heatmap`, `GET /api/heatmap/cell` |
| パラメータ | `HEAT_WEEKS`, `HEAT_MIN_COUNT`, `HEAT_LEVEL_*`, `HEAT_ABS_*` |

**プロト版 UI（2026-08 追加分）**

- マップ風グリッド（全セル着色、予定なしは薄灰）
- 長い工程名の省略表示（マスタ名の制御文字除去）
- 工程行クリック → 部品一覧をその SHOP で絞り込み（`/parts?shop=xxxx`）
- 表示切替: SHOP / SHOP×JOB / **部品**
- 部品表示: 縦=部品、横=期間、色=部品の緊急度

### 1.2 実績リードタイム + Hs 取込

| 項目 | 内容 |
|---|---|
| 画面 | `/lt`（管理者のみ・サイドバー「実績LT」） |
| 詳細仕様 | [フェーズ2_実績リードタイム.md](フェーズ2_実績リードタイム.md) |
| 概要 | OCTPuS 実績から SHOP 間リードタイムを集計。FLEXSCHE の Hs 列も取込 |
| DB | `t_routing.hs` 追加、`t_shop_lt_stat` 新設 |
| 主な API | `GET /api/lt/stats`, `POST /api/lt/recompute`, `POST /api/lt/adopt` |
| パラメータ | `LT_MODE`（既定 `fixed`）, `LT_ACTUAL_PERCENTILE`, `LT_MIN_SAMPLES`, `LT_ACTUAL_MAX_DAYS` |

**所見（実データ）**

- 全 SHOP の中央値を一括適用すると赤部品が約8k→15kに増えるため、`LT_MODE=fixed` を維持
- 推奨値は `/lt` 画面から SHOP 単位で採用する運用を想定
